ESQUEMA DE LA ESTRUCTURA DEL PROYECTO ONDORI

Raíz/
- artisan: Helper de Laravel para comandos Artisan.
- composer.json: Dependencias PHP del proyecto.
- package.json: Dependencias y scripts frontend (Vite, Tailwind, etc.).
- README.md: Documentación general del proyecto.
- ESTRUCTURA.md: Descripción de la arquitectura del proyecto.
- GIT_WORKFLOW.md: Flujo de trabajo con Git.
- NOTAS.md: Notas del proyecto.

BD/
- ONDORI.sql: Dump de la base de datos (estructura y datos iniciales).
- ESTRUCTURA_WEB.txt: (este archivo) resumen esquemático de la estructura del proyecto.

app/
- Http/Controllers/: Controladores que manejan las solicitudes HTTP.
  - Controllers/: Controladores específicos del dominio (p. ej. Auth, Shop).
  - Requests/: Form Request validation classes.
- Mail/: Clases para envíos de correo (PurchaseConfirmation, WelcomeEmail).
- Models/: Eloquent models (Administrador, Categoria, Direccion, Hombre, Mujer, Oferta, Pedido, PedidoDetalle, User, Usuario).
- Providers/: Service providers (AppServiceProvider).
- View/Components/: Componentes Blade reutilizables.

bootstrap/
- app.php: Inicialización de la aplicación.
- providers.php: Registro de providers.
- cache/: Archivos de cache compilados.

config/
- *.php: Archivos de configuración (app, auth, database, mail, queue, services, session, etc.).

database/
- factories/: Model factories para pruebas (UserFactory.php).
- migrations/: Migraciones de base de datos para crear tablas.
- seeders/: Seeders para poblar DB (DatabaseSeeder.php).

public/
- index.php: Punto de entrada público para la aplicación (front controller).
- robots.txt: Instrucciones para bots.
- build/: Activos compilados por Vite (manifest.json, assets/).
- img/: Imágenes públicas (hombre, mujer, ofertas, etc.).

resources/
- css/app.css: Archivo principal de Tailwind + estilos personalizados.
- js/: Scripts frontend (app.js, bootstrap.js).
- views/: Plantillas Blade (.blade.php): vistas públicas y de admin.
  - layouts/: Plantillas base.
  - partials/: Fragmentos reutilizables.
  - components/: Componentes Blade.
  - admin/, auth/, checkout/, shop/: Vistas por sección.

routes/
- web.php: Rutas web públicas.
- auth.php: Rutas de autenticación.
- console.php: Definición de comandos Artisan personalizados.

storage/
- app/: Archivos subidos y privados.
- framework/: Caché de framework (views, cache, sessions).
- logs/: Archivos de log de la aplicación.

framework/
- cache/, sessions/, testing/, views/: Cachés y artefactos del framework.

vendor/
- Dependencias instaladas por Composer (Laravel y paquetes de terceros).

tests/
- TestCase.php: Clase base para pruebas.
- Feature/: Tests funcionales (ExampleTest.php, ProfileTest.php).
- Unit/: Tests unitarios.

Archivos y elementos importantes adicionales:
- tailwind.config.js: Configuración de Tailwind (rutas `content`, extend theme, plugins).
- vite.config.js: Configuración de Vite para build frontend.
- phpunit.xml: Configuración de PHPUnit.
- postcss.config.js, tailwind.config.js: Herramientas para procesar CSS.
- public/build/assets/*.css: CSS compilado por Vite (generado). Contiene utilidades de Tailwind y clases personalizadas.

Notas sobre lo que hace cada tipo de archivo (resumen):
- Controllers: Reciben la petición, validan datos (usando Requests) y devuelven vistas o JSON.
- Models: Representan tablas de DB y encapsulan lógica de acceso a datos.
- Views (Blade): Plantillas que generan HTML, usando componentes y layouts.
- CSS/JS en resources: Código fuente frontend que se compila con Vite a `public/build`.
- Config/*.php: Ajustes de la aplicación (base de datos, mail, colas, etc.).
- Migrations/Seeders: Definen la estructura y datos iniciales de la base de datos.
