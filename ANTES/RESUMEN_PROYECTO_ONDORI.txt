                            1. INTRODUCCIÓN
================================================================================

1.1 Objetivo
-----------
Desarrollar una plataforma de e-commerce para la venta de ropa online que permita
a los usuarios navegar, filtrar y comprar productos de diferentes categorías
(Hombre, Mujer, Ofertas). La aplicación debe ofrecer una experiencia de usuario
intuitiva y centrada en la visualización de productos.

1.2 Herramientas y Tecnología
-----------------------------
En esta aplicación se han utilizado las siguientes tecnologías, seleccionadas
por su eficiencia, capacidad de organización y reducción de código repetitivo:

================================================================================
                           2. TECNOLOGÍAS EMPLEADAS
================================================================================

2.1 Backend
-----------
 PHP 8.3.6 + Laravel 12.50.0: Framework PHP que permite desarrollar aplicaciones
   web escalables con una arquitectura clara y organizada basada en MVC.
   Laravel simplifica la configuración, gestión de rutas y autenticación.

 MySQL 8.0 + XAMPP: Sistema de base de datos relacional utilizado para almacenar
   toda la información de productos, usuarios y pedidos. Gestionado a través
   de phpMyAdmin para facilitar la administración.

 Eloquent ORM: Facilita el acceso a la base de datos evitando código repetitivo
   gracias a sus modelos que incluyen operaciones CRUD básicas
   (save, delete, update, find, all).

 Blade Templates: Motor de plantillas de Laravel que permite crear vistas
   reutilizables con sintaxis limpia y herencia de plantillas.

 Laravel Breeze: Sistema de autenticación preconstruido que implementa
   registro, login, logout y verificación de email de forma segura.

2.2 Frontend
------------
 HTML5 + CSS3 + Tailwind CSS: Estructura semántica y diseño moderno con
   framework CSS utility-first que permite crear diseños personalizados
   rápidamente sin escribir CSS desde cero.

 JavaScript (ES6+): Para interactividad del lado del cliente, validaciones
   de formularios y dinamismo en la interfaz.

 Blade Components: Componentes reutilizables de Laravel que mantienen
   la consistencia visual y reducen la duplicación de código.

 FontAwesome: Biblioteca de iconos para mejorar la interfaz visual
   y la experiencia de usuario.

2.3 Base de Datos
-----------------
 MySQL 8.0: Motor de base de datos relacional robusto y escalable.
 phpMyAdmin: Interfaz web para administración de la base de datos.
 Tablas principales: Administradores, Usuarios, Hombre, Mujer, Ofertas, Direccion.

2.4 Herramientas de Desarrollo
-------------------------------
 XAMPP: Entorno de desarrollo local con Apache, MySQL y PHP.
 Composer: Gestor de dependencias para PHP.
 npm: Gestor de paquetes para assets frontend.
 Git: Control de versiones para el seguimiento de cambios.

                           3. ARQUITECTURA
================================================================================

3.1 Arquitectura General
-----------------------
El sistema sigue una arquitectura cliente-servidor basada en el patrón MVC
(Model-View-Controller). El backend y frontend están desacoplados y se comunican
mediante peticiones HTTP.

Backend (Servidor):
- Desarrollado con Laravel, contiene toda la lógica de negocio, gestión de
  usuarios, productos y administración.
- Implementa autenticación personalizada usando tabla Administradores.
- Gestión de productos en categorías separadas (Hombre, Mujer, Ofertas).

Cliente (Frontend):
- Desarrollado con Blade templates y Tailwind CSS.
- Interfaz responsive y moderna.
- Sistema de carrito de compras funcional.

3.3 Flujo de Datos
------------------
1. Usuario realiza petición HTTP a través del navegador
2. Laravel recibe la petición y enruta al controlador correspondiente
3. Controlador interactúa con los modelos (Eloquent)
4. Los modelos consultan/actualizan la base de datos MySQL
5. Controlador pasa datos a la vista (Blade)
6. Vista renderiza el HTML con Tailwind CSS
7. Respuesta enviada al navegador

---------------------------------

- /cart/add -> Añadir al carrito
- /cart/update -> Actualizar carrito
- /cart/remove -> Eliminar del carrito
- /cart/clear -> Vaciar carrito
- /checkout -> Procesar pago
- /checkout/success -> Confirmación de compra

11.3 Flujo de la Aplicación
----------------------------

11.3.1 Flujo de Usuario:
1. Usuario accede a la página principal (/)
2. Navega por categorías (/mujeres, /hombres)
3. Visualiza detalles de producto (/vistaProducto/{id})
4. Añade productos al carrito (/cart/add)
5. Visualiza carrito (/carrito)
6. Procesa checkout (/checkout)
7. Recibe confirmación (/checkout/success)

11.3.2 Flujo de Administrador:
1. Admin inicia sesión (/login)
2. Accede a menú "Admin" en navegación
3. Ingresa al panel (/admin/dashboard)
4. Gestiona productos (tab Productos)
5. Gestiona usuarios (tab Usuarios)
6. Edita/Elimina usuarios con confirmación

11.3.3 Flujo de Autenticación:
1. Usuario completa formulario de registro
2. Laravel valida y crea usuario en tabla Usuarios
3. Usuario inicia sesión con credenciales
4. Sistema verifica en tabla Administradores (para admin)
5. Sesión iniciada con permisos correspondientes
6. Redirección según tipo de usuario

11.4 Base de Datos
------------------

Tablas Principales:
- Administradores: (ID_Admin, Nombre, Email, Password)
- Usuarios: (ID_USUario, Nombre, Apellido, Email, Telefono, Password)
- Hombre: (id_producto, nombre, descripcion, tipoRopa, color, talla, precio, stock, foto)
- Mujer: (id_producto, nombre, descripcion, tipoRopa, color, talla, precio, stock, foto)
- Ofertas: (id_producto, nombre, descripcion, precio, stock, foto)
- Direccion: (ID_Direccion, ID_USUario, Calle, Ciudad, CP, Pais)

Relaciones:
- Usuarios -> Direccion (Uno a Muchos)
- Administradores -> Gestión de todo el sistema
- Productos -> Categorías separadas (Hombre/Mujer/Ofertas)
